# Burger Menu REST API 🍔

A robust, lightweight RESTful API for managing a burger restaurant menu built with **Node.js** and **Express.js** as part of the DecodeLabs Backend Development project.

---

## 🚀 Features

- **Fetch All Burgers:** Retrieve the complete burger menu using `GET /burgers`.
- **Fetch Single Burger:** Retrieve a specific burger by its unique ID using `GET /burgers/:id`.
- **Add New Burger:** Create new menu items using `POST /burgers` with input validation ("Gatekeeper" rule).
- **Update Burger:** Modify existing menu items using `PUT /burgers/:id`.
- **Delete Burger:** Remove items from the menu using `DELETE /burgers/:id`.

---

## 🛠️ Tech Stack

- **Runtime:** Node.js
- **Framework:** Express.js
- **Testing Tools:** Thunder Client / Postman
